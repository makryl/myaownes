MyaowNES HTML Embed Tool

This is online tool for embedding your NES game into single HTML file with MyaowNES emulator. Read more info under the form. Star the repo on GitHub.

About

In embed mode emulator will run game immediately after page loads, and hide some UI, so users can't change rom file.

Browser's cache and storages

Submitted config will be used as default. When user changes some options in game, new config is stored in internal browser's storage. If you change config for existing page, you should reset options using in-game menu or clear browser's cache and storages to see changes.

Audio auto-start

Usually browser blocks audio until first user gesture. By default, emulator will show special "start screen", when audio is blocked, in order to unblock audio. If audio is important for your game from very beginning, before user press any button in game – keep default setting. If your game already has similar screen, or audio is not important – you can disable the option.

Config

You can keep only changed options in the config.

  • start_screen: 0 - disabled, 1 - enabled (default)
  • volume: range 1-10, default 10
  • auto_aspect: 0 - disabled, 1 - enabled (default)
  • overscan: 0 - disabled (default), 1 - enabled
  • auto_save_period: period of saving SRAM in seconds, range 1-300, default 60
  • show_fps: 0 - disabled (default), 1 - enabled
  • fast_forward_scale: range 1-5, default 4
  • region: 0 - NTSC, 1 - PAL, 2 - Auto (default), 3 - Dendy
  • bind_*: uses SDL_scancode_names, all binds must be unique or disabled, use empty string with quotes "" to disable bind
